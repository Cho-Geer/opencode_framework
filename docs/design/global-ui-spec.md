# 全局 UI / 样式 / 交互 统一规范
适用于：前端页面、组件风格、弹窗、表格、表单、颜色、字体、间距、图标、状态

==========================================================
# 1. 全局基础规范
==========================================================

## 1.1 主题色
主色：#1677FF（蓝色，专业、信任、系统感）
成功色：#00B42A
警告色：#FF7D00
危险色：#F53F3F
文字主色：#1D2129
文字次要色：#4E5969
文字灰色：#86909C
边框色：#E5E6EB
背景色：#F2F3F5

## 1.2 字体
中文：思源黑体 / 微软雅黑
英文/数字：Inter
字号层级：
- 标题：16 / 18 / 20 / 24
- 正文：14
- 小字：12
- 辅助文字：11

## 1.3 间距
模块间距：20px
卡片内边距：16px
表单间距：12px
按钮高度：32 / 36 / 40

## 1.4 圆角
按钮：6px
输入框：6px
卡片：8px
弹窗：10px

==========================================================
# 2. 页面结构规范
==========================================================

## 2.1 布局
- 顶部导航栏：固定
- 左侧菜单：固定
- 内容区域：居中、最大宽度 1200px
- 移动端：自适应、单列展示

## 2.2 卡片
- 白底卡片
- 轻微阴影
- 标题左对齐、加粗
- 底部操作按钮右对齐

## 2.3 表格
- 斑马线隔行变色
- 表头固定
- 文字左对齐
- 操作列右对齐

==========================================================
# 3. 表单规范
==========================================================

## 3.1 输入框
高度：36px
内边距：0 12px
边框：#E5E6EB
聚焦：#1677FF
提示文字：#86909C

## 3.2 按钮
主按钮：蓝色背景、白色文字
次按钮：灰色边框、灰色文字
文字按钮：无边框、蓝色文字
禁用：透明度 0.5、不可点

## 3.3 下拉选择
选项高度：32px
 hover 背景：#F2F3F5

==========================================================
# 4. 弹窗 / 抽屉 / 提示
==========================================================

## 4.1 弹窗
宽度：520px / 640px / 800px
标题：16px 粗体
底部按钮：右对齐
取消：左
确认：右（主按钮）

## 4.2 提示信息
成功：绿色对号
警告：黄色感叹号
错误：红色叉号
加载：蓝色转圈

==========================================================
# 5. 状态展示规范
==========================================================

## 5.1 状态标签
- 待处理：灰色
- 处理中：蓝色
- 已完成：绿色
- 异常/失败：红色
- 已过期：橙色

## 5.2 空状态
居中图标 + 简短提示
底部加“新建”按钮

==========================================================
# 6. 交互体验规则
==========================================================

- 点击可点区域出现手型光标
- 加载必须显示 Loading
- 提交按钮点击后禁用防重复
- 表单实时校验，错误红色提示
- 列表无数据显示空状态
- 所有操作必须有成功/失败反馈

==========================================================
# 7. 移动端适配规则
==========================================================

- 小屏自动单列
- 按钮自动占满宽度
- 弹窗全屏展示
- 表格横向可滚动
- 字体不小于 12px

==========================================================
# 8. 图标与图标风格
==========================================================

- 线性图标
- 24px 统一大小
- 颜色跟随文字主色
- 简洁、现代、统一

==========================================================
# 9. 动画与过渡（轻微、不花哨）
==========================================================

- 弹窗：淡入 + 缩放
- 开关：平滑过渡
- 按钮：hover 轻微上浮
- 页面切换：淡入

==========================================================
# 10. 可直接交给前端开发的最终总结
==========================================================

所有页面必须遵守：
统一颜色 → 统一字体 → 统一间距 → 统一圆角 → 统一按钮 → 统一弹窗
统一表格 → 统一表单 → 统一状态 → 统一空状态 → 统一加载 → 统一反馈
