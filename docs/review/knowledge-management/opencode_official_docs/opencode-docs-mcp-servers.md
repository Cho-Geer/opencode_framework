# OpenCode Official Docs: MCP Servers
Source: https://opencode.ai/docs/mcp-servers/
Fetched: 2026-06-05

## Key Points for UC7KS Cross-Reference

1. Local MCP servers: type: local, command array
2. Remote MCP servers: type: remote, url
3. OAuth support with automatic flow
4. MCP tools named as: <server-name>_<tool-name> (e.g., context7_resolve-library-id)
5. Can enable/disable per agent
6. Context7 official MCP server: https://mcp.context7.com/mcp (remote type)
