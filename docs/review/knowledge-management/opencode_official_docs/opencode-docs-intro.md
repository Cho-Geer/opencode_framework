## Key Points for UC7KS Cross-Reference

1. OpenCode is an open-source AI coding agent by Anomaly
2. GitHub: https://github.com/anomalyco/opencode (NOT github.com/opencode)
3. 160K+ GitHub stars, 900+ contributors, 7.5M monthly devs
4. Features: LSP enabled, multi-session, share links, any model via Models.dev, any editor
5. Install: curl -fsSL https://opencode.ai/install | bash
6. Config: /connect command for providers, /init for AGENTS.md
7. Plan mode: Tab key to switch between Build and Plan modes
8. Share: /share command for sharing conversations
