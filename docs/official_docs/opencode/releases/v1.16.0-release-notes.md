# OpenCode v1.16.0 Release Notes
Source: https://github.com/anomalyco/opencode/releases
Fetched: 2026-06-05

## v1.16.0 (Latest — June 5, 2026)

### Core Improvements
- Managed workspace cloning that keeps dirty and untracked files
- Moving sessions between workspaces and directories
- Proper OpenAI model support through AWS Bedrock
- Skill discovery and file-based agent loading
- GitHub Copilot usage tracking for token-based billing
- `run --replay` for interactive session replay
- Improved startup time (~38% by @StarpTech)

### Core Bugfixes
- Fixed Vue syntax highlighting
- Restored full ACP session replay
- Fixed shell cancellation races
- Fixed delegated tasks losing reasoning variants
- Fixed OpenAI websocket sessions idle
- Fixed Windows path normalization
- Fixed prompt corruption near wide characters
- Fixed ACP cancel aborts active run
- Fixed SAP AI Core Anthropic Opus 4.7+ reasoning

### TUI (Terminal UI)
- Improved experimental session switcher
- Truncated long sidebar file paths
- Toast for variant hotkey with no variants
- Routed question responses to right session
- Fixed background task spinner sticking

### Desktop
- Added color themes
- Local server startup failures shown in app
- Thinking level selector for v2 prompts
- Servers tab in Settings
- Update button
- Fixed session review refresh and VCS diff caching

### Extensions
- GitHub refuses commit without git author identity
