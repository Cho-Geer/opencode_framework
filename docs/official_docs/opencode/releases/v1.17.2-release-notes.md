## Plugin Hook Support

### `tool.execute.before` ✅
Available since early versions. Full support for built-in and MCP custom tools.

### `tool.execute.after` ✅ (confirmed v1.17.2)
Confirmed implemented in upstream source at `packages/opencode/src/session/tools.ts`. Uses same trigger pattern as `tool.execute.before`:

```typescript
// Both built-in and MCP tools use the same trigger pattern
yield* plugin.trigger("tool.execute.before", { tool, sessionID, callID }, { args })
// ...
yield* plugin.trigger("tool.execute.after", { tool, sessionID, callID, args }, output)
```

**Key difference**: `tool.execute.after` receives `input.args` (original tool args), while `tool.execute.before` receives `output.args`.
