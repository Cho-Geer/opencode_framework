# brainstorming

Transforms ambiguous requirements into structured, implementation-ready designs.

## Two-tier Usage

### Micro Card (default, 100-300 tokens)
Before acting, answer internally:
1. Goal clear? (one sentence)
2. Scope/files clear?
3. Success criteria clear?
4. Risk level: low / normal / high?
5. Need to ask QoderWork?

If not asking QoderWork, state assumptions briefly and proceed.

### Full Brainstorming (complex/high-risk tasks)
Read FULL.md for complete process.
**Trigger**: architecture decisions, refactoring, migration, permission/DB/framework core changes, multi-file/multi-module tasks, repeated failures.
